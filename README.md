# CodeAlpha Tasks

This repository contains the Android apps I built during my CodeAlpha internship.

## Projects

### 1. Random Quote Generator
An Android app that shows a random motivational quote every time the user taps the button.
- **File:** `RandomQuote.apk`

### 2. Flashcard App
An Android app for creating and revising flashcards to help with studying.
- **File:** `flashcard.apk`

## How to Install
1. Download the `.apk` file from this repository.
2. Open it on your Android phone.
3. Allow "Install from unknown sources" if asked.
4. Install and open the app.

## Tech Stack
- Android (Java/Kotlin)
- Android Studio
